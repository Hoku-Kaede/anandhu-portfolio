# Anandhu Portfolio

A single-page portfolio with a VHS-style project shelf and a hidden macOS desktop.

- `index.html` — portfolio entry point. Press the Konami code (↑ ↑ ↓ ↓ ← → ← → B A) to enter the hidden desktop.
- `mac.html` — interactive macOS-style desktop with boot screen, sign-in (`bingo`), apps, draggable icons, Launchpad and a secret folder (answer `kato`).
- `project.html` — standalone project detail view.

Static site. No build step.
